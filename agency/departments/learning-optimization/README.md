# Learning & Optimization Department - Hermes-Ecom Drop Shipping Agency

## Department Mandate
**Primary Function**: Continuous improvement through systematic learning, heuristic updates, and performance optimization across all campaigns.

### Key Objectives:
- Maintain and update learnings/HEURISTICS.md with campaign outcomes
- Implement PROTOCOL-03 learning loop for all closed campaigns
- Identify patterns and extract actionable heuristics
- Update prediction models and bias correction
- Ensure no repeatable mistakes through knowledge accumulation
- Feed learning insights back into all other departments

### Learning Loop Framework (PROTOCOL-03):

#### Trigger Conditions:
- **Campaign Closure**: Any campaign reaching Kill / Scale / Iterate verdict
- **Protocol Compliance**: All campaigns must produce written learning
- **No Wasted Ad Budget**: Learning required for every closed campaign

#### Learning Process:
1. **Score Predictions**: Compare predicted vs. actual for all metrics
2. **Isolate Root Cause**: Single-link attribution of outcomes
3. **Extract Heuristics**: Falsifiable, portable knowledge
4. **Promote/Demote**: Heuristic status management (PROVISIONAL → SUPPORTED/CONTESTED/RETIRED)
5. **Close Loop**: Next campaign benefits from updated knowledge

## Department Protocols (Continuous Improvement):

### PROTOCOL-03 Implementation:

#### 1. Prediction Scoring:
```
# Template from learnings/_TEMPLATE.md
Campaign: Product Name
Date: 2026-MM-DD
Metric: CTR
Predicted: 2.0%
Actual: 1.2%
Error %: -40.0%
Root Cause: Creative hook mismatch
Heuristic Updated: Problem-oriented hooks outperform aspirational for €35 products
```

#### 2. Root Cause Analysis:
- **Single-Link Attribution**: One factor per outcome
- **No Diffusion Blame**: Clear responsibility assignment
- **Actionable Insights**: Portable to next campaign

#### 3. Heuristic Lifecycle:
- **PROVISIONAL**: First observation, tiebreaker only
- **SUPPORTED**: ≥3 consistent observations, scoring modifier
- **CONTESTED**: Contradiction, flag for decisive test
- **RETIRED**: Falsified, prevent relearning dead ideas

#### 4. Calibration Log:
```
Campaign | Date | Metric | Predicted | Actual | Error % | Bias Adjustment
---------|------|--------|-----------|--------|---------|---------------
ProductA | 2026-08-30 | CTR | 2.0% | 1.2% | -40% | Discount by 40% next prediction
```
