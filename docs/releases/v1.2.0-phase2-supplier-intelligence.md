## 1. Overview
Phase 2 transitions the system from theoretical candidate economics to **grounded supplier reality**. It deploys real-time supplier auditing, pure mathematical margin reconciliation with packaging and freight volatility buffers, and continuous drift monitoring across six critical failure vectors.

---

## 2. Key Additions & Features

### A. Supplier Verification Contract & Database
- **Schema (`schemas/supplier_verification.schema.json`)**:
  - Full tracking of warehouse coordinates (`warehouse_lat`, `warehouse_lon`), shipping class (`USPS`, `EU DPD`, etc.), packaging grade, defect rates, and stock depth.
  - **Supplier Stability Score** ($0.00\text{--}1.00$):
    $$\text{Stability} = 0.4 \times (1 - |\text{Price Drift}|) + 0.3 \times \min(1, \text{Stock}/200) + 0.2 \times (1 - \text{Defect Rate}/10) + 0.1 \times \text{Domestic}$$
- **SQLite Storage**:
  - `supplier_verifications` table with indexes on `candidate_id`, `status`, and `verified_at_unix`.
  - Migration script: `scripts/migrations/002_supplier_verifications.sql`.

### B. Pure Margin Reconciliation Engine (`agency/core/margin_reconciler.py`)
- Replaces estimated costs with verified landed costs.
- Integrates a **4% shipping volatility buffer** and package grade uplifts ($+\$0.45$ custom box, $+\$0.30$ kraft box, $+\$0.15$ mailer).
- Enforces 2026 EU customs regulations (€3.00 flat per non-EU import; €0.00 for verified domestic EU warehouses) and ex-VAT margin math.
- Emits `MARGIN_COMPRESSED` flags when margin degrades by $\ge \$2.00$ or multiple falls below $2.0\times\text{COGS}$.

### C. Supplier Verification Bot (`agency/bots/supplier_verification_bot.py`)
- Audits inventory depth (<30 units triggers emergency status).
- Cross-checks declared domestic fulfillment claims against verified warehouse coordinates and carrier tiers.

### D. Continuous Supplier Drift Detector (`agency/bots/supplier_drift_detector.py`)
- Monitors active candidates for **6 Drift Triggers**:
  1. `PRICE_SPIKE` ($\ge 8\%$ increase in landed cost)
  2. `STOCK_DEPLETED` ($< 30$ units remaining)
  3. `WAREHOUSE_RELOCATION` (rerouting from domestic to international transit)
  4. `LEAD_TIME_INFLATION` (shipping max exceeding 7 days)
  5. `SUPPLIER_API_SILENCE` (unresponsive feed or low confidence $< 0.30$)
  6. `SKU_FRAGMENTATION` (split into fragmented variant costs)
- Automatically emits `sig-supplier-drift-*` trade proposals (`SUPPLIER_SWITCH` or `SELL_KILL`) into Ahmad's approval queue.

### E. CLI Operations Terminal
- `python -m agency.cli verify [candidate_id]`
- `python -m agency.cli reconcile <candidate_id>`
- `python -m agency.cli drift [--json]`
- `python -m agency.cli ver-history <candidate_id>`

## 3. Migration Instructions

1. **Apply SQLite Migration**:
   ```bash
   python scripts/migrate.py up
   ```
2. **Verify Migration Status**:
   ```bash
   python scripts/migrate.py status
   ```
3. **Run Full Test Suite**:
   ```bash
   npm test
   ```
   *Expected result: 29/29 tests passed in < 2.0s.*
4. **Smoke Test Production Pipeline**:
   ```bash
   python -m agency.cli verify cand-cj-sku-magnetic-cord-6p
   python -m agency.cli reconcile cand-cj-sku-magnetic-cord-6p
   python -m agency.cli drift
   ```

## 4. Rollback Plan
If rollback is required:
```bash
python scripts/migrate.py rollback 002_supplier_verifications
```
Reverts the table and indexes cleanly without affecting candidate or trade signal ledgers.
